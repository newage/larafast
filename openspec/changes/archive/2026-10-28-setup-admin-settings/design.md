# Design

## Context

Filament 5 на `/admin` вже підключений, `discoverPages` вказує на `app/Filament/Pages`, сторінок немає. У БД немає таблиці налаштувань. Конфіги з `env()` оформлені за зразком `config/site.php`. Мотивація — у `proposal.md`, вимоги — у `specs/claude-settings/spec.md`.

## Goals / Non-Goals

**Goals:**
- Один шар читання «БД, інакше `.env`» для 7 ключів.
- Редагування на одній Filament-сторінці.

**Non-Goals:**
- Споживач налаштувань (виклики Claude API), кешування читання, налаштування поза цими 7 ключами, ресурс зі списком рядків.

## Decisions

- **Таблиця `settings` (`key` унікальний, `value` nullable text), модель `Setting`.** Ключі збігаються з назвами з `.env`. Альтернатива — колонка на кожен параметр: гірше розширюється.
- **Дефолти в `config/claude.php` через `env()`** за зразком `config/site.php`; `.env.example` отримує ті ж 7 ключів. Альтернатива — дублювати дефолти в коді (відкинуто воронкою).
- **Читання через одну точку** (клас/метод `Setting::resolve($key)`): непорожній рядок у БД, інакше `config('claude.*')`. Споживач у майбутньому викликає лише її.
- **Сторінка Setup — Filament `Page` із формою (`app/Filament/Pages/Setup.php`)**, поля за типами: текст, число, select для `CLAUDE_EFFORT`. Збереження — upsert 7 рядків; порожнє значення зберігається як `null`.
- **API-ключ:** значення шифруються (`encrypted` cast); у формі поле-пароль із placeholder-маскою (префікс + останні 4 символи); порожнє поле при збереженні не змінює рядок.
- **Мова:** підписи, повідомлення й назва пункту меню польською.

## Risks / Trade-offs

- Два джерела значень → сторінка показує дефолт з `.env` як підказку (placeholder), щоб було видно, звідки береться значення.
- Зміна `APP_KEY` робить збережений ключ нечитабельним → при помилці дешифрування читання повертається до `.env`, у формі ключ показується як не заданий.
